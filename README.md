# 餐厅评论文本分析与智能回复平台 — 项目介绍
## 项目概述
本项目是一个面向餐厅评论数据的一站式文本分析平台,围绕评论数据的 统计分析、方面挖掘、评分预测、智能回复 四大核心能力构建,共包含 8 个 Python 模块,覆盖从原始数据处理到可视化展示、再到商家自动回复生成的完整链路。

## 解决的核心问题
针对商家面对海量评论时难以高效处理的痛点,项目解决三类问题:

- 评论文本理解 :自动识别评论涉及的方面(口味/环境/服务/价格/卫生/位置)、情感倾向及客户特征
- 评分预测 :基于文本特征预测各维度评分,辅助量化口碑
- 回复生成 :结合商家信息与评论内容,自动生成个性化回复

## 技术架构
- 数据处理 :pandas、numpy
- 中文分词 :jieba(配合5套官方停用词表)
- 特征工程 :TF-IDF + 情感特征(12维) + 文本统计特征 拼接
- 机器模型 :Voting 集成(TF-IDF + 情感特征 + 统计特征)
- 智能回复 :智谱 GLM-4-Flash API,无 API 时降级为本地规则模板
- GUI :Tkinter(支持异步生成、回复编辑与重生成)
